# 原価の集計とAiMとの比べ（2026-11-19）

> `PRINCIPLES.md`（方針書）1・2章の「自作がAiMより高くつくなら作る意味は無い」を数字で確かめるために作った。
> 詳しい表は2本：自作の部品表`docs/design/cost_comparison_20261119_ecologger.md`（リポジトリの資料だけから。Webは見ていない）、
> AiMの見積もり`docs/design/cost_comparison_20261119_aim.md`（国内の販売サイトとAiM本社の2026年11月版の価格表。税込、2026-11-19に確認）。

## 1. 結論

| | 1台分（税込） | 5つの機能のうち |
|---|---:|---|
| **自作 Ver.2（SUGOの形、11/8）** | **約8.8万円**（幅7.6万〜10.5万円） | 1〜5すべて |
| 自作 Ver.2（作手の形、12/5。12V側UPSを含む） | 約9.2万〜9.9万円（幅8.0万〜11.5万円） | 1〜5すべて |
| AiM B：1〜3の最低限（MXq＋ACC3＋油温・油圧センサー＋SmartyCam 4 Corsa） | **約63万円** | 1〜4（画面は白黒）。5は無い |
| AiM A：いちばん近い構成（MXS 1.3＋センサー＋SmartyCam 4 Corsa） | 約93万円 | 1〜4。5は無い |
| AiM A＋他社のLTE（PodiumConnect/Micro） | 約100万円〜 | 1〜5 |

- **自作は、同じ機能のAiMの約1/7〜1/10。** 方針書の基準（AiMより十分安い）を満たしている。ユーザーの見立て「10万円を切る」も、中央の値では合っている（上の端では少し超える）
- **AiMにはピットへのLTEのライブ表示が無い**（本社の価格表にも国内の販売サイトにも無い）。やるなら他社品を足す
- AiMの費用の約半分は映像（SmartyCam 4 Corsa、315,700円）。自作で映像にかかっているのはカメラ一式・ドック・延長で約1.6万円
- 毎月かかるのは、SIM（SORACOM planX3）と自宅のサーバーの電気代で約300〜700円。AiMには無い費用だが、ライブ表示（AiMに無い機能）のためのもの

## 2. 比べるときに気をつけること

- **油温・油圧のセンサーの差**：自作は、もとから車に付いていたDefiのメーター・センサーから値を分けて取っている（数えていない。買えば約4万〜10万円）。AiMの見積もりにはセンサー（約5万円）が入っている。
  Defiの分を足しても自作は約13万〜20万円で、AiMの1/3より安い
- **自作の値段の4割は見積もり・推定**（リポジトリに買った値が無い）。いちばん不確かなのは、シールドの基板の製作費・UPSモジュール・12V側のUPS・2口の充電器・取付具など（部品表の「値段がいちばん不確かな5つ」）
- **数えていないもの**（方針書2章のとおり）：Claudeの利用料、作業の時間、失敗した部品（1枚目のUNO Qなど約2万円）。自宅のサーバー（ROCK 5B、約2.3万円）は前のサブプロジェクトの使い回しで、1台分には入れていない
- AiMの国内価格は1つの販売サイトの表示。品切れ・取り寄せの品が多く、店によって1〜2割の差がありうる。旧型のSmartyCam 3 Sportが手に入れば約15万円下がる
- 機能の中身は同じではない：AiMは取付の手間が少なく、完成品としての信頼がある。自作は車のCANをNCEC用に自分で読み解いていて（AiMのNC用のプロトコルにはスロットル開度が無い）、ライブ表示と自前の解析アプリがある

## 3. 2台目以降

- 2台目からは、自宅のサーバー・道具・ソフトを使い回せるので、上の1台分の値段がそのままかかる（基板は最低5枚の発注なので、2台目の基板代はもう払ってある）
- エコランの車のように車載画面がスマホでカメラも載せない形なら、モニター・カメラまわり（約3.4万円）が要らず、約5万円台になる見込み（集計していない）

## 4. このあとの使い方

- 部品・サービスを足すときは、1章の自作の行に足して、AiMとの差が保たれるかを見る（方針書6章の2）
- 値段の分からない所は、買ったときに部品表の行の「状態」を「記録」に直していく
