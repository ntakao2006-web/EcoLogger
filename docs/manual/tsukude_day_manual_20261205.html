1. 取り付けの確認（出走前・スイッチOFFのまま）

  1. 手元スイッチがOFFなのを確かめてから触る。
  2. 充電器：高出力の口＝ロガー（ドック）。モニターは別の口。全部挿してからスイッチを入れる。
  3. ドックにカメラ・HDMI・電源。ドックは電源を入れる前につなぐ（動いている途中で差し替えると認識しない）。
  4. GNSS・LTEアンテナのコネクタを指で押し込む。シールドのSDが奥まで入っている。
  5. カメラの向き、ケーブルが走行の振動で引っ張られないか（手で揺する）。

2. 電源ON → 確認（毎回・エンジンを掛ける前）

  1. スイッチを入れる。電源を入れるだけで記録・録画が始まる（止めるボタンは無い）。
  2. 約1〜2分で車載画面が出る。時刻が進んでいれば本体は動いている。
  3. エンジンを掛けると水温・回転数が出る。
  4. エンジンを掛けた瞬間に画面が消えたら、ドックが落ちている（記録は続いている）。スイッチを切り、本体が完全に止まるまで待ってから入れ直す（本体のUPSが粘るので、止まるまで2分ほどかかることがある。すぐ入れ直しても直らない）。
  5. ピットのページを使うなら、位置・速度が出れば記録とLTEはOK（測位するまで出ない。最初の送信まで約2分）。

録画は、本体の空きが少なくなると回収済みのものから古い順に入れ替わる。1日の最後に必ず回収する（6章）。

3. 線（コントロールライン）の確認

  • ロガーの線は設定済み（東側のメインストレート、ストレートをまたぐ構造物の下。コースとピットレーンをまたぐ幅40m。走る向きは時計回り＝ストレートを南へ）。現地で登録し直すことは無い。
  • 朝のコースウォークで、公式の計測の線（路面の線・ビーコン）の位置を写真に撮る。ロガーの線は地図から引いた推定で、ずれていてもラップタイムは変わらない（ずれるのは1周目とピットに入った周の区切りだけ）。
  • 走り出して数周で、車載画面の周が増え、前の周のタイムが出ること（1周は約30〜40秒）。出なければ7章。
  • ピットに入った周は、ピットの周として扱われないことがある（ピットレーンとコースが近く、見分けの値が仮のため）。走ったあとに記録で合わせ直す。

4. 枠と枠のあいだ

  • 走行会なのでラップのリセットは要らない（周の番号が続くだけ。前の周・ベストのタイムは正しい）。
  • 枠のあいだ、長く止まるときはスイッチを切ってよい。入れ直せば記録・録画は自動で再開する（ファイルが分かれるだけ）。
  • 見るところ：スイッチがON、車載画面の時刻が進み、周が増えている。

5. 走っている間に見るところ（ドライバー）

車載画面油温水温すること
赤い帯と警告音120℃以上110℃以上クーリング走行。下がらなければピットへ

値は車の設定（tools/setups/vehicles/ncec.json の dash）。油温の運用の目安は110℃注意／120℃クーリング／130℃ピットイン（ncec-roadster の track/thermal-limits.md）。Defiのメーターが正。

6. 走り終えたら（止める）・回収

  1. スイッチを切る。記録・録画は電源OFFで閉じる（最後の約1秒が欠けるだけ）。
  2. （1日の最後・PC）ロガーの電源を完全に切ってからドックを外し、本体をPCとUSBで直結（PCから給電されて起動する）。
  3. 回収アプリを開き、本体が見えたら「回収する」。結果の「取れたもの／取れなかったもの／次にすること」を読む。
  4. シールドのSD：USBを抜いて電源を切り、SDを抜いてPCのカードリーダーへ → もう一度「回収する」。
  5. 回収しても本体からは消えない。

7. 困ったとき

症状まずやること
車載画面が真っ白明るさが上がりきっている。メニューを開いていないときの上・下ボタンで下げる
車載画面が「信号なし」2分待つ（ロガーが自動で出し直す）。だめならHDMIを抜き差し
画面が止まった・消えた走ってよい（記録は続いていることが多い）。ドックか電源が落ちている。枠が終わってからスイッチを切り、本体が完全に止まるまで待って（2分ほど）入れ直す。戻らなければ充電器・ドックの差し込みを確かめる。起きた時刻をロガー担当へ
水温・回転数が No dataエンジンが掛かっているか。OBD2のタップが外れていないか
油温が No data基板・配線。Defiのメーターで見て走ってよい
周が増えない・前の周が出ないタイムは公式が正。ピットでロガー担当へ（線の位置・向き）
ピットのページに出ない記録には影響しない。測位待ち・電波。起動から最初の送信まで約2分
