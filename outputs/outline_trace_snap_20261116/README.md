# なぞった線の吸い付き（SUGO 11/8、2026-11-16）

解析アプリのコース図のエディタに足した「なぞる」（SP-10-34）の確かめ。

## 画面での確かめ

`sugo_trace_snap.png`：解析アプリの画面でマウスの動きを送り、縁の約1.6 m外を60 mなぞった結果を、航空写真に重ねて描き直したもの。

- 黄：前の縁（自動のコース図。この所は地図の道路縁から）
- 青：なぞった線（縁から中央値1.64 m外、±0.3 mの揺れ入り）
- 赤：吸い付いて置き換わった線。前の縁から中央値0.09 m・いちばん離れた所で0.21 m

## まとめての確かめ（自動のコース図の縁から、ずらしたなぞりを作って）

- 同じ区間（60〜150 m、30区間）を横へ −1・−0.5・0・+0.5・+1 m ずらしてなぞった5本：吸い付いたあと、真ん中の1本からのずれは中央値0.13 m、上位10%で0.3 m（なぞった線どうしは最大1 m）
- 地図の道路縁も候補に入れたとき（アプリと同じ）：0.5〜2.5 m ずらしたなぞり（中央値1.32 m）が、地図の線から中央値0.20 mへ
- 写真だけのとき、地図の線からは中央値0.75 m。写真の縁と地図の道路縁はもともと所により1 mほど違う（地図の線が路肩の外にある所がある）ので、地図の線は答えにしていない

## 苦手な所

- ピットロードとの境目のように、路面が両側に続いて境目が何本もある所は、探す幅（画面の24画素）の内でいちばん目立つ境目へ行くことがある。寄って探す幅を細くしてなぞる
